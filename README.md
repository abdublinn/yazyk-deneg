# Язык денег

Книга для собственника о деньгах своего дела: учёт, прибыль, цены и затраты. Не теория из учебника, а выводы из десяти лет работы с мебельным бизнесом.

Живая книга, дописывается глава за главой.

**Читать:** https://abdublinn.github.io/yazyk-deneg/
